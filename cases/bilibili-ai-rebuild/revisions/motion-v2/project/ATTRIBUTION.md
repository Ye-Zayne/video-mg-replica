# 素材与品牌形状来源

所有场景布局、文字、运动和图形组件为本工程代码。未嵌入参考视频画面、逐帧截图或逐帧描摹序列。

- 参考视频：用户提供的 41630436033-1-192.mp4，作者胡泊Hubo。独立 narration.m4a 保留原始配音、音乐与音效。
- OpenAI Blossom：纠正上版错误的网格形近似，采用 OpenAI 标志矢量形状，内嵌为 SVG path；作者 OpenAI，文件来自 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:OpenAI_logo_2025_(symbol).svg)，其页面标记 PD-textlogo / Trademarked。[OpenAI 品牌页](https://openai.com/brand/) 提供官方品牌背景。用于原片涉及 OpenAI 的说明画面，不表示背书。并非原片逐帧抽取。
- 磁带、显示器、盾牌、锁、芯片、列表等为独立 SVG/CSS 绘图。
- 字体依赖 macOS 本机字体，详见 README；字体文件未打包。
