## 保留的差异

人物、人物照片及手部实拍为图形替代，属于用户允许的改编，不能称为原片对应画面的复刻。字体、复杂摄影材质、三维手部/电脑/磁带、景深、烟雾等仍为近似。新闻正文部分压缩排版；字幕保留上版OCR校订结果，未全面重新逐字听审。音轨保留参考的配音、音乐和音效。本轮没有新增原片画面到生产工程；OpenAI标志改用公开品牌SVG，详见工程ATTRIBUTION.md。

## 复用

工程根目录执行 `npm ci`、`npm run studio`。正式全片导出用 `npm run render:final -- rebuild.mp4`；截取指定帧范围用 `npm run render -- clip.mp4 --frames=起帧-末帧`，后者会按合成时间输出相应音频。段落时长在timeline.json，动作细节在五个场景模块，统一由帧时间驱动。旧版留在案例原目录，本轮独立存放于 revisions/motion-v2。

## 最终技术对照

`qa/delivery-compare/metrics.json` 以每300帧抽36张源/新版/差异图；技术项通过，平均RGB MAE为63.82/255。该值不是相似度百分比，也不能与前一版不同采样步长的平均值直接比较。人物改编和材质差异会显著增加差值。完整成片保留原AAC，标准参考的填充尾部比实际音频长545个48kHz采样（约11.35ms），未重编码裁剪原配音。
