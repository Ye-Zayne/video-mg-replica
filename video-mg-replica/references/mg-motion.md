# MG 动效取证与实现

目标是重建屏幕上的可见行为，不是猜出 AE/剪映的预设名称。静态形状、父层运动和局部遮罩常同时作用；先分解再拟合。

| 观察 | 应测量 | 可编辑实现 |
|---|---|---|
| 物体从屏外滑入 | 首次可见、anchor 轨迹、速度变化、过冲和落定 | React 容器 transform + 连续曲线 |
| 线条逐渐画出 | 路径方向、起点、端帽、可见长度/时间 | SVG path + pathLength、dasharray、dashoffset |
| 字从边界擦开 | 字形是否移动、遮罩前沿方向/角度、羽化宽度 | 外层固定 mask/clipPath + 内层文字 |
| 字符逐个跳入 | 分字方式、逐字延迟、每字锚点和基线 | 每字独立 span，由全局 frame 计算 |
| 数字翻滚/增长 | 中间数值、位数、单位固定位置、进位方式 | 实时文字或每列裁切滚动，保留最终排版 |
| 圆环/图表出现 | 圆心、起始角、占比、描边宽度、标签时序 | SVG circle/path，数值驱动 |
| 整体推近/摇移 | 固定参照物、镜头原点、背景是否同动 | 父组变换；不要复制到所有子元素 |
| 弹性形变 | 极值、相位、阻尼、横纵比例关系 | 有证据的弹簧/分段曲线；不要默认弹跳 |
| 图形 morph | 顶点/拓扑对应、曲线切线、途中轮廓 | 拓扑匹配的 SVG 路径插值；不匹配则分解 |
| 辉光/残影 | 层数、间距、透明度、色差、拖尾方向 | 固定数量可编辑副层，按时间偏移采样 |
| 空间旋转 | 透视、消失点、前后遮挡、光影 | CSS 3D 或 Three.js；先验证遮挡与透视 |

至少看动作前一帧、首见、25%/50%/75%、落定和退出后一帧；快速动作补全帧。保留绝对帧号，并区分 Sequence 内局部帧与整个片段帧。

样本是证据，不自动成为新缓动段。例如 0–18 帧滑入，用两个端点加一条 cubic-bezier，并用 4/9/14 帧验证；只有停顿、反向或过冲有证据时才分段。CSS cubic-bezier 的时间是 x 轴，要解 x(t)=progress 再取 y(t)，不能直接把 progress 代入三次多项式。模板 `motion.ts` 已实现此解算。

文字拆分使用 `Intl.Segmenter` 的 grapheme，避免 emoji/组合字符拆坏；逐字容器要保持原字距与换行。描边建议 `pathLength=1`、dasharray=1、dashoffset=1-progress；不要通过横向拉伸假装画路径。

随机、粒子和噪声使用固定种子。不要依赖 Date.now、setInterval、CSS 自运行动画或浏览器播放时钟。模糊/阴影增加前先检查边缘、对齐与时序，防止用模糊掩盖布局误差。

关闭动效的静态模式直接回到指定落定状态；不要简单把所有动作 progress 设成 1 导致退出动作把元素藏掉。镜头、遮罩、文字内部效果也要走同一静态模式。
